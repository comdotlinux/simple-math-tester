# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue:
open the repository's **Security** tab and choose **Report a vulnerability**
(GitHub private vulnerability reporting).

Include what is affected (Android app, iOS app, web app at math.munich-tech.de,
the Pages functions under `functions/`, or a GitHub workflow), how to reproduce it,
and the version (Settings in the app shows it).

## Supported versions

Only the newest release on Google Play and the App Store, and the current web
build, get fixes.

## Scope notes

The app sends nothing anywhere except a report that a grown-up confirms
(see the privacy policy in the app). Secrets live only in GitHub and Cloudflare
settings, never in this repository.
