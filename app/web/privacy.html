Privacy policy

Simple Math Tester is a free arithmetic practice app for children, without ads. This policy covers the Android and iOS apps and the web version. Last updated: 21 November 2026.

What the app collects

No personal data. There are no accounts, no analytics, no advertising and no tracking. The app makes one kind of request only: a report that a grown-up chooses to send (see Reporting a problem below). It makes no other request.

What the app stores on your device

To keep your progress between sessions, the app saves your answers, the questions you marked as wrong, your level in each kind of exercise and your settings (such as sound and vibration) on your own device: in the app's private storage on Android and iOS, and in your browser's local storage on the web. This data never leaves the device. Uninstalling the app, or clearing the site's data in the browser, deletes it.

The app works offline. The Android app requests internet access only to send a report that a grown-up chooses to send.

The web version

The web version is served by Cloudflare Pages. Like any web host, Cloudflare receives your IP address and the usual request details (such as browser type and the page requested) when your browser loads the site, in order to deliver it and protect it from abuse. See the Cloudflare privacy policy.

All files the app needs, fonts included, come from the app's own site; the app loads nothing from other websites. After the first visit your browser keeps a copy of the app so it also starts offline. This copy contains only the app's files, not personal data.

The Impressum page

The Impressum (the provider identification) is a separate page on the same site. The app opens it in your browser only when you choose Impressum in the settings. That page, and only that page, loads Cloudflare Turnstile, which receives the visitor's IP address and browser signals to tell people from bots. See the Cloudflare privacy policy.

Reporting a problem

A question can be marked as wrong; the mark stays on the device and sends nothing. A report is sent only when a grown-up chooses Send report, picks a reason from a list and passes the grown-up check (typing a number shown in words, which slows down young children but is not a lock). Send a problem report in the settings works the same way, with the kind of problem picked from a list. Each report is one request to the app's own site, math.munich-tech.de, served by Cloudflare. It contains only the question code (or the kind of problem), the reason, the app version, the platform and the app language: no name, no progress, nothing typed. A function on that site turns it into a public issue on GitHub that holds no personal data. Like any web request, the report gives Cloudflare your IP address; the function does not store it.

Report a problem in the settings opens a new issue on GitHub in your browser, prefilled with the app version and platform, for a longer description. The app sends nothing itself there. If you submit that issue, it is public, and GitHub's own privacy policy applies.

Children

The app is made for children and collects no personal data from anyone, children included. Only a grown-up can send a report, and a report holds no personal data.

Changes and contact

If this policy changes, the new version is published in the app and on the web version's privacy page with a new date. For questions, write to the developer e-mail address shown on the app's Google Play listing.
